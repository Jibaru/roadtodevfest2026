Welcome to the agentic era

  • 2023: we chatted with LLMs
  • 2024–25: LLMs got tools and started doing things
  • 2026: software is becoming teams of agents that plan, act and cooperate
  • An agent = model + instructions + tools + memory, in a loop

Why Go for agents?

  • Agents are concurrent by nature — goroutines and channels are the native fit
  • One static binary: the whole show tonight ships as a single file
  • Typed tools: the function signature IS the contract the model sees
  • Boring, fast, deployable — perfect for agents that must not fall over

The architecture (clean & boring on purpose)

cmd/api // wire everything internal/ battle/domain/ // entities + repo interfaces + errors battle/service/ // the show's state machine battle/infra/ // memory | file | embedded — same interface agents/ // ADK: 2 rappers + 1 judge tts/ // Gemini TTS → WAV realtime/ // WebSocket hub, drops slow clients web/ // go:embed — UI inside the binary

Swapping storage is one constructor line. The agents are behind interfaces too — the show ran offline in rehearsal.

Did you notice the comebacks?

  • Each battler has a persistent ADK session — it remembers its own verses
  • The opponent's last verse is injected into the prompt each round
  • Memory + context = round 3 answering round 1's punchline
  • The audience vote is the human-in-the-loop
